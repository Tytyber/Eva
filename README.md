# 🎙️ Ева — Голосовой ИИ-Ассистент

**Ева** — это персональный голосовой ИИ-ассистент с поддержкой распознавания речи, синтеза речи, долгосрочной памяти и автоматического выполнения задач.

---

## ✨ Возможности

- 🎤 **Распознавание речи** в реальном времени (RealtimeSTT + Silero VAD)
- 🗣️ **Синтез речи** (pyttsx3)
- 💬 **Интеллектуальный диалог** с долгосрочной памятью
- 📝 **Автоматическое выполнение задач**: создание файлов, написание кода, чтение файлов
- 🧠 **Планирование и оркестрация** через LLM (OpenRouter API)
- 🌐 **Википедия-поиск** и получение текущего времени

---

## 🛠️ Архитектура

```
src/

├── audio/
│   ├── audio_engine.py        # Распознавание речи (Whisper + Silero VAD)

│   ├── conversation.py        # История диалога ( ConversationHistory )

│   ├── memory.py              # Долгосрочная память (LongTermMemory)
│   └── router.py              # Классификация запросов: action/chat
├── llm/
│   ├── answers.py             # Генерация голосовых ответов после действий
│   ├── dialog_answer.py       # Обработка диалога ( ChatHandler )
│   ├── generate_code.py       # Генерация кода
│   └── orcestration.py        # Выполнение планов ( AgentOrchestrator )
└── tools/
    └── init.py                # Базовые инструменты: файлы, время, поиск
```

## 📦 Установка

### 1. Требования

- Python 3.10+
- GPU с поддержкой CUDA (рекомендуется для Silero VAD и Whisper)
- OpenRouter API-ключ

### 2. Зависимости

```bash
pip install -r requirements.txt
```

Особенно важные:
- `silero-vad>=5.1` — детектор речи
- `faster-whisper>=1.0` — распознавание речи
- `pyttsx3` — синтез речи
- `openai>=2.0` — доступ к LLM через OpenRouter
- `RealtimeSTT` — реальное время распознавания

### 3. Настройка API-ключа

Откройте `src/main.py` и замените:

```python
API_KEY = "sk-or-v1-ваш-ключ"
```

## 🚀 Использование

### Запуск в голосовом режиме

```bash
cd src
python main.py
```

Ассистент прослушает микрофон и будет реагировать на команды.

### Примеры команд

**Разговор:**
- «Привет, как дела?»
- «Расскажи шутку»
- «Что ты умеешь?»

**Задачи:**
- «Создай файл notes.txt с текстом "Привет, мир!"»
- «Напиши функцию Python для сложения двух чисел в файл calculator.py»
- «Прочитай файл notes.txt»
- «Какое сейчас время?»

**Выход:** скажите «стоп», «выход», «хватит» или «пока».

## 🔍 Как это работает?

1. **Распознавание речи**  
   RealtimeSTT (Whisper + Silero VAD) ловит речь и превращает её в текст.

2. **Классификация намерения**  
   `intent_classifier.py` отправляет запрос LLM, который:
   - Определяет тип запроса (разговор / задача)
   - Выбирает подходящие инструменты
   - Извлекает аргументы для вызова

3. **Выполнение задачи (если нужно)**  
   `AgentOrchestrator.execute_plan()` выполняет шаги в правильном порядке, передавая результаты между ними.

4. **Генерация ответа**  
   `generate_tts_response()` формирует короткий, «говорящий» текст без markdown и технических деталей.

5. **Сохранение памяти**  
   В фоне `LongTermMemory` извлекает темы и сохраняет резюме для будущих диалогов.

## 🛠️ Добавление новых инструментов

1. Создайте функцию в `src/tools/init.py`:

```python
def my_new_tool(param1: str, param2: int) -> dict:
    """
    Описание инструмента.
    """
    try:
        # ваш код
        return {"status": "success", "message": "Готово"}
    except Exception as e:
        return {"status": "error", "message": str(e)}
```

2. Зарегистрируйте его в `VoiceAssistant`:

```python
self.orchestrator.register_tool("my_new_tool", tools.my_new_tool)
```

3. В `intent_classifier.py` добавьте логику сопоставления (или положитесь на LLM).

## 📝 Примечания

- По умолчанию используется модель `poolside/laguna-m.1:free` (бесплатная).
- Для распознавания речи по умолчанию — `base`, для синтеза — системный голос (лучше установить русский).
- Память сохраняется в `assistant_memory.json`.

---

## 🐛 Известные ограничения

- Требуется стабильный интернет для OpenRouter API.
- Whisper base может ошибаться на шумных записях.
- pyttsx3 использует системные голоса (на Windows лучше работает с русским языком).
